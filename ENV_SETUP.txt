===========================================
ENVIRONMENT VARIABLES SETUP GUIDE
===========================================

Create a file named ".env" in the "asaan-heal-flow" folder with the following content:

-------------------------------------------
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key-here
-------------------------------------------

HOW TO GET THESE VALUES:
------------------------
1. Go to Supabase Dashboard: https://supabase.com/dashboard
2. Select your project
3. Go to Settings → API
4. Copy "Project URL" → This is your VITE_SUPABASE_URL
5. Copy "anon public" key → This is your VITE_SUPABASE_ANON_KEY

IMPORTANT NOTES:
----------------
- No spaces around the = sign
- No quotes needed around values
- File must be named exactly ".env" (with the dot at the start)
- File location: asaan-heal-flow/.env
- Never commit this file to Git
